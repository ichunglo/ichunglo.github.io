# FDA indication curation — release gate

The live indication table is a manually verified pilot, **not a complete review of the 1,766-drug catalog**. Do not present the Drugs@FDA application queue as approved indications, or publish a claim of complete FDA coverage from it.

## FDA-only source path

1. Build `data/generated/fda-application-review-queue.csv` from the [Drugs@FDA downloadable tables](https://www.fda.gov/drugs/drug-approvals-and-databases/drugsfda-data-files) with `scripts/build_fda_review_queue.py`. Record the FDA snapshot date and ZIP checksum from its summary file.
   The same script emits `data/generated/fda-efficacy-supplement-candidates.csv` with approved efficacy supplements and their available FDA letters/labels. These are **possible** indication changes, not verified indication events; some efficacy supplements do not create a new indication.
   Run `scripts/build_fda_label_candidates.py` after the queue to collect [openFDA label](https://open.fda.gov/apis/drug/label/) indication text for candidate applications. The output is another **unverified review aid**. It reflects current labeling, may be missing or associated with a different product, and does not establish historical indication approval dates. Keep the API batch cache in ignored `tmp/` so interrupted retrieval can resume.
2. For each catalog drug, confirm the active moiety and all relevant NDA/BLA applications. A salt, four-letter biologic suffix, brand name, combination product, or cell/gene therapy may require manual alias review. An unmatched name is **not** proof of no FDA approval.
3. Read the FDA approval letters for the original application and all indication-changing supplements. Determine the first U.S. approval date for **each indication**, not merely the original application date. A conversion from accelerated to traditional approval is not a new indication.
4. Check the most relevant FDA label for the indication wording, qualifying mutation or patient group, prior-therapy requirements, and required combination therapy. Capture a dated, direct FDA label URL and the FDA approval-record URL. The label may have changed since the initial approval.
5. Record verified indication rows in `data/curated/fda-approved-indications.csv`. Perform an explicit completeness check for that drug; the presence of one row does not prove all its U.S. indications are covered.
6. For drugs with no confirmed U.S. approval, retain a separate evidence-backed review state. Never translate a missing Drugs@FDA name match into “not approved”; the source may omit aliases or products handled elsewhere at FDA.
7. Enter a source-backed disposition in `data/curated/fda-review-decisions.csv` only after checking the drug's product identity, all relevant applications, and the submission history for possible indication changes. Run `scripts/build_fda_review_ledger.py`; its generated ledger accounts for all 1,766 drugs and leaves unreviewed ones as `pending`. `verified_complete` means all FDA-approved uses found in the reviewed applications are captured in the curated indication table. `unresolved_after_review` documents a remaining uncertainty; it never means FDA did not approve the drug.

## Publication condition

Before announcing full FDA coverage, every catalog drug must have a completed FDA status review, all verified U.S. indications must have indication-specific dates and source links, and all unresolved or out-of-scope cases must be clearly labeled. The review-ledger summary must report zero pending drugs, and any `unresolved_after_review` drugs must be disclosed rather than counted as confirmed U.S. nonapprovals. Run the curated-data validator, dashboard tests, a clean production render, and live-page checks before deployment. Until then, keep the reader-facing count labeled as partial curated coverage.

## 2026-10-12 candidate-stage checkpoint

The FDA Drugs@FDA snapshot dated 2026-10-09 has 3,344 distinct candidate applications across the 1,766 catalog drugs; 355 catalog drugs have no exact/prefix name match and remain unresolved, **not** classified as unapproved. The openFDA label retrieval found indication text for 1,721 drug-application candidate rows spanning 949 catalog drugs. These counts are triage coverage, not verified indication coverage. The 4,245 approved efficacy-supplement candidates require event-level review. The manually curated indication table currently has 32 rows for 29 drugs. Nine single-application drugs with only original FDA submissions have documented complete reviews; 1,757 remain pending. The presence of an indication row for another drug does not imply its audit is complete. The ensitrelvir record is specifically for post-exposure prophylaxis of COVID-19, not treatment; the daprodustat record requires at least four months on dialysis.
